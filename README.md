# UNUS (WIP; MVP)
Software KVM that interfaces with WiFi Direct for Windows and Android devices (for now)

UNUS is an alternative to a physical KVM switch that allows multiple devices and computers to receive input from a single mouse and keyboard setup. However, UNUS does so much more than a traditional KVM switch, as it allows seamless switching between devices, just move your mouse to the edge of the screen. Keyboard input naturally follows the device in focus, and so does your clipboard history. You also get to customize your device arrangement.

You will literally forget that you ever had more than one device by how smooth UNUS delivers (trust).

## What makes this different from, oh I don't know, the many other software KVMs?

Synergy, Barrier, DeskFlow, Input Leap, and Mouse Without Borders are all fine as software KVMs. I used to use some of these for my setup for a year or two. However, there were definitely some certain limitations and issues that felt clunky or just downright interfered with my workflow. I did decide to just deal with such issues (*krsst* incredible latency, device disconnect *krsst*), but eventually I couldn't handle it. And so one day I woke up and decided I was gonna develop my own that promises a hassle-free experience meant to enhance your workflow, and not to deter from it.

Anecdotes aside, UNUS is indeed different. UNUS interfaces via WiFi Direct. Straight P2P. No need for LAN connectivity. It's as simple as two devices establishing a connection. Two, three, or four into one, hence UNUS.
